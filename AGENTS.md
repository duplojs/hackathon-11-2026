## Développement avec DuploJS

- Avant d’écrire un utilitaire ou d’utiliser une API native ou tierce, rechercher la fonction adaptée à la manipulation souhaitée dans le [routeur API](node_modules/.pnpm/@duplojs+agents-kit@0.1.0-beta.8_@duplojs+code-config@0.1.0-beta.8_conventional-commits_b64ec699e1009a96853f66c3b9a6c3e3/node_modules/@duplojs/agents-kit/docs/API.llms.md). Suivre les liens vers le domaine puis la référence pertinente, et utiliser l’équivalent DuploJS dès qu’il existe.
- Pour une recherche de concept ou un problème de composition, de typage ou d’erreur, consulter le [routeur des concepts](node_modules/.pnpm/@duplojs+agents-kit@0.1.0-beta.8_@duplojs+code-config@0.1.0-beta.8_conventional-commits_b64ec699e1009a96853f66c3b9a6c3e3/node_modules/@duplojs/agents-kit/docs/concepts.llms.md), puis uniquement les pages et exemples pertinents.
- Appliquer les contrats et patterns documentés, notamment pour les contraintes et les résultats `Either`. Ne pas inventer d’API ni contourner le typage pour résoudre un doute.
- Utiliser les skills DuploJS installés pour les procédures spécialisées liées à la tâche.

Les chemins des routeurs sont relatifs au dossier de ce fichier ; résoudre ensuite chaque lien depuis le document qui le contient.
