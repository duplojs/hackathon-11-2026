# Exercice 07 : `rightPipe`

> **État : 07 ✅ identique à TypeScript** (Sprint 4).

## Problème étudié

Source : [`projects/07`](../../projects/07). `rightPipe` enchaîne `add`, puis
`divide`, qui peut produire une erreur.

| Problème | Détail |
|---|---|
| Entrée gauche | Elle est renvoyée sans appeler d'étape. |
| Étapes dépendantes | Chaque callback reçoit la valeur droite déballée de l'étape précédente. |
| Court-circuit | La première gauche arrête les callbacks suivants. |
| Valeur finale | Un résultat nu est enveloppé une seule fois en `Success`, à la fin. |
| Fichiers multiples | `add` et `divide` sont importés depuis leurs modules source. |

Sortie de référence observée :

```text
[ '-12' ]
division par zéro impossible
```

## Variantes

Voir [`variations/README.md`](../../variations/README.md) :
`07-three-steps`, `07-plain-step`, `07-left-input` et `07-division`.

## Stratégie

| Source | Go | Décision |
|---|---|---|
| `rightPipe(e, f1, …)` | `e` lié une fois, puis `if e.IsLeft() { … } else { … }` imbriqués | ADR-10 |
| Paramètre de callback fléché | Variable liée dans un bloc Go, corps-expression inliné | Pas de closure pipeline ni de `func` literal pour ces flèches |
| Étape gauche | Coercition vers le type de résultat, sans étape suivante | Court-circuit |
| Dernière valeur nue | `EitherSuccessOf[T](value)` | Une seule enveloppe finale |

## Go produit

**[observé]** Extrait de `projects/07/dist/index.ts/index.ts.go` :

```go
Generated_1 := Sourced_add.Sourced_add
Generated_2 := (float64)(1)
Generated_3 := (float64)(2)
Generated_4 := Generated_1(Generated_2, Generated_3)
var Generated_5 shard_dependencies.Either[float64]
if Generated_4.IsLeft() {
	Generated_5 = Generated_4
} else {
	var Generated_9 shard_dependencies.Either[float64]
	{
		Sourced_value := Generated_4.Value
		Generated_6 := Sourced_divide.Sourced_divide
		Generated_7 := Sourced_value
		Generated_8 := (float64)(0)
		Generated_9 = Generated_6(Generated_7, Generated_8)
	}
	Generated_5 = Generated_9
}
```

La portée de bloc permet d'inliner plusieurs callbacks qui réutilisent le même
nom de paramètre sans collision Go.

## Limites

- Seule la forme directe est traitée ; la forme curryfiée est refusée.
- Les callbacks fléchés à corps-bloc ne sont pas inlinés par le handler
  `rightPipe`.
- Étapes asynchrones (`async`/`await`) : Sprint 5.
