# Exercice 09 : `group` et `Either2`

> **État : 09 ✅ identique à TypeScript** (Sprint 4).

## Problème étudié

Source : [`projects/09`](../../projects/09). Plusieurs calculs produisent un
Either ; `group` renvoie le premier gauche ou regroupe les valeurs droites.

| Problème | Détail |
|---|---|
| Valeurs hétérogènes | Gauche `float64`, succès `[]float64` : A (`Either[V]`) ne suffit pas. |
| Premier gauche | La première erreur est propagée avec son information et sa valeur. |
| Réussite | Toutes les valeurs droites sont regroupées ; un groupe vide réussit avec `[]`. |
| Évaluation | Les calculs de la collection ont déjà été exécutés avant `group`. |

Sortie observée :

```text
[ 'transaction annulée' ]
```

## Variantes

Voir [`variations/README.md`](../../variations/README.md) :
`09-group-all-right`, `09-group-first-left` et `09-group-empty`.

## Stratégie

La règle de type produit `Either2[float64, []float64]` seulement lorsque les
types gauche et droit diffèrent. `group` évalue son argument une fois, alloue
`out` avec capacité `len(arr)`, parcourt avec `range`, arrête au premier gauche
et appelle `Either2FromLeft`; sinon il retourne
`Either2SuccessOf(out)`. L'accès droit est obtenu via `getEitherValueAccess`
(`Value` pour A, `Right` pour A').

## Go produit

**[observé]** Extrait de `projects/09/dist/index.ts/index.ts.go` :

```go
Generated_28 := make([]float64, 0, len(Generated_27))
Generated_31 := false
var Generated_29 shard_dependencies.Either2[float64, []float64]
for _, Generated_30 := range Generated_27 {
	if Generated_30.IsLeft() {
		Generated_29 = shard_dependencies.Either2FromLeft[float64, []float64](Generated_30)
		Generated_31 = true
		break
	}
	Generated_28 = append(Generated_28, Generated_30.Value)
}
if !Generated_31 {
	Generated_29 = shard_dependencies.Either2SuccessOf[float64, []float64](Generated_28)
}
```

## Résultats et coût

**[observé]** L'exercice et les trois variantes correspondent à `tsx`.
`Either2FromLeft` et `Either2SuccessOf` sont inlinés par le compilateur Go.
La slice `out` s'échappe au tas car elle devient la valeur de `Success`; cette
allocation est nécessaire pour conserver la collection.

| Contrôle (séquence native équivalente à `check-all`) | Résultat |
|---|---|
| Exercice 09 : transpilation, `go vet`, `go run`, comparaison exacte | ✅ 1/1 |
| Variantes 09 : mêmes contrôles et `tsc --noEmit` | ✅ 3/3 |

## Limites

- Un groupe d'objet (`Record`), de getters ou d'une source qui n'est pas une
  slice est refusé explicitement.
- `matchInformation` sur `Either2` est refusé explicitement ; le callback gauche
  et le callback droit demandent des accès et types distincts.
- `asyncGroup` est hors périmètre (Sprint 5).
