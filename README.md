## Objectif

Étudier s’il est possible de transpiler du DuploJS vers Go pour obtenir un programme performant tout en conservant le comportement d’origine. Les dix exercices se trouvent dans `projects/01` à `projects/10`. Le projet `projects/00` présente une solution et sert de point de départ.

Analysez les problèmes et leurs variations, puis concevez des transformers génériques et composables. Justifiez vos choix de représentation, leurs conséquences attendues sur les performances et la mémoire, ainsi que leurs limites. Les assistants et agents IA sont autorisés ; vous pouvez créer un skill pour encadrer vos exemples et guider votre implémentation.

## Suivi des exercices

Pour chaque exercice abordé, documentez dans son README le problème, votre stratégie et sa justification, les résultats observés, les cas non couverts et les limites. Si vous ne trouvez pas de solution, expliquez votre démarche et ce qui vous bloque. Distinguez les résultats vérifiés des hypothèses.
